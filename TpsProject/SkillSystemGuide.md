# 스테이지 스킬 선택

## 확인 방법

MainScene을 실행하고 해당 스테이지의 적을 모두 처치합니다.
기존 스테이지 전환 대기 시간(기본 3초) 뒤 스킬 카드 3개가 표시됩니다.
카드 하나를 클릭하면 강화가 적용되고 다음 스테이지가 시작됩니다.
씬에 UI나 컴포넌트를 직접 추가하지 않아도 됩니다.

선택 중에는 시간이 멈추고 마우스가 표시됩니다. 카메라 회전과 무기 입력은 차단되며,
선택에 사용한 클릭으로 총이 발사되지 않도록 처리했습니다.
화면이 좁으면 카드가 세로로 나열됩니다. 획득한 스킬은 선택 화면 아래에 표시됩니다.
UI 문구는 기존 게임 HUD와 같은 영문입니다.

## 스킬

| 화면 이름 | 효과(한 단계당) | 최대 단계 |
| --- | --- | --- |
| POWER ROUNDS / 강화 탄환 | 총 피해량 +20% | 3 |
| PIERCING ROUNDS / 관통 탄환 | 추가 적 1명 관통, 두 번째 적에게 50% 피해 | 1 |
| HEAVY STRIKE / 강타 | 근접 피해량 +25% | 3 |
| WIDE SWING / 넓은 휘두르기 | 근접 사거리 및 공격 각도 +20% | 3 |
| AMMO RECOVERY / 탄약 회수 | 근접 처치마다 예비 탄약 +3발 | 3 |
| TOUGHNESS / 강인함 | 최대 체력 +20 및 체력 20 회복 | 3 |

퍼센트 강화는 기본값에 합산합니다. 강화 탄환 3단계는 총 피해량 1.6배입니다.
관통 탄환은 벽을 통과하지 않으며 적의 여러 콜라이더에 중복 피해를 주지 않습니다.
근접 공격 각도는 최대 180도이며, 탄약 회수는 현재 스테이지의 총 보유량 상한을 넘지 않습니다.
근접으로 직접 처치했을 때만 탄약을 돌려받습니다. 총 처치에는 적용되지 않습니다.

이미 최대 단계인 스킬은 후보에서 제외됩니다. 남은 스킬이 3개 미만이면 반복 가능한 보상이 채워집니다.
- FIRST AID: 체력 40 회복.
- VITALITY: 최대 체력 +5, 체력 5 회복.
- SUPPLY DROP: 바로 다음 스테이지에만 탄약 +15발(기본 90발이면 105발).

## 데이터와 전환 원리

`PlayerSkills`는 플레이어별로 이번 플레이의 스킬 단계를 보관합니다.
공격력 등의 수치는 이 컴포넌트에서 계산하므로 공용 WeaponData 에셋이나 적의 능력치는 바뀌지 않습니다.
스테이지가 바뀌어도 스킬은 유지하고, 새로운 플레이어로 새 게임을 시작하면 초기화합니다.
최고 점수를 기록한 플레이의 스킬 구성은 점수와 함께 DB에 저장합니다.
이는 기록 조회용이며, 다음 게임에서 스킬 효과를 다시 적용하는 영구 강화는 아닙니다.

## 점수와 스킬 기록

적 처치, 스킬 선택, 플레이 종료 시 점수와 선택한 스킬의 현재 단계를 함께 전송합니다.
반복 보상은 선택 횟수를 기록하므로 탄약 보급 효과를 사용한 뒤에도 선택 기록이 남습니다.
서버는 최고 점수를 갱신할 때 점수와 스킬 구성을 한 번에 교체합니다.
같은 플레이에서 점수 변화 없이 스킬만 선택했다면 해당 최고 기록의 스킬 정보를 보완합니다.
다른 플레이에서 낮거나 같은 점수를 올려도 기존 최고 기록의 스킬은 덮어쓰지 않습니다.

전송 실패 시 점수, 플레이 ID, 스킬 목록을 묶어서 기기에 보관하고 재시도합니다.
로그인 화면의 각 순위 아래에서 스킬 이름과 단계를 볼 수 있습니다.
웹에서는 순위의 `선택 스킬`을 펼치거나 로그인 후 본인의 최고 기록 영역에서 확인합니다.
이전 기록은 스킬 정보가 없으므로 `No skill record` 또는 `선택 기록 없음`으로 표시됩니다.
예전 플레이에서 선택했던 스킬은 사후 복구할 수 없습니다.

서버 변경 사항을 Render에 배포해야 온라인 저장이 적용됩니다.
서버 시작 시 기존 PostgreSQL 테이블에 기록용 컬럼을 자동 추가하며, 새 환경 변수는 필요 없습니다.

## 스테이지 전환

`StageManager`는 마지막 적의 사망을 확인한 후 `SkillSelectionUI.Show`를 호출합니다.
UI는 중복되지 않는 세 후보를 만들고, 선택을 딱 한 번 적용한 뒤 `BeginNextStage`를 호출합니다.
다음 스테이지에서는 기존대로 총알을 초기화합니다. 선택 중 사망하면 보상을 주거나 다음 스테이지를 시작하지 않습니다.

## 수정할 파일

- `Assets/Scripts/PlayerSkills.cs`: 배율, 보유 단계, 최대 단계, 표시 이름과 설명.
- `Assets/Scripts/SkillSelectionUI.cs`: 카드 배치, 색상, 선택 및 일시정지 처리.
- `Assets/Scripts/SkillIcon.cs`: 스킬 아이콘.
- `Assets/Scripts/StageManager.cs`: 스테이지 완료 후 선택 화면을 여는 시점.

분리된 Unity 테스트 프로젝트에서 스킬 효과, 관통/벽/중복 판정, 실제 근접 처치 보급,
마우스 카드 클릭, 스테이지 전환, 새 게임 초기화와 여러 해상도의 UI를 검사했습니다.
